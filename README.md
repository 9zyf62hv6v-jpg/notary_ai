# ИИ-Ассистент для нотариуса

Веб-приложение для автоматизации юридической рутины. 
Позволяет генерировать юридические документы по текстовому описанию с помощью нейросетей, а также рассчитывать госпошлины.

## 🛠 Стек технологий
* Python
* Интеграция с LLM (ИИ)
* SQLite (База данных)
* HTML/CSS (Веб-интерфейс)

## 🚀 Как запустить
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите приложение: `python main.py`
